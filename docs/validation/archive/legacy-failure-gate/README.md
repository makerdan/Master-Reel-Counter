# Legacy validation archive

Historical only. These are not instructions. The only Failure Gate source is .agents/skills/failure-gate-unified/SKILL.md once installed.

The owner authorized retirement of the older gate and, separately, removal of
only its CI checks. Unified is not installed by this change. No task is
admitted, rebound, marked PASS, or reopened by this archive.

Original relative paths are preserved beneath the archive where practical.
Retired executable sources and gate-only tests have `.retired.txt` appended
so ordinary script/test discovery cannot run them. Old skill definitions and
their distributable ZIPs are deleted, not retained as alternate instructions.
Reports, plans, task snapshots, and ledger files retain their original bytes
and IDs. `moves.json` records source/destination paths and SHA-256 checksums.

The archived SQLite ledger is historical data, not a live coordinator. Do not
execute its old stored paths or use its records as current permission. The
platform task board and its history are not deleted or rewritten.

See `ADAPT.md` for retained tools and data. The retirement search report lists
remaining references, including platform-managed caches that are history in
place rather than files this repository can safely relocate.
