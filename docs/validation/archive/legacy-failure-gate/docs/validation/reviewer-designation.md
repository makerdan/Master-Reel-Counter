# Project-local human reviewer designation

The person who answered **“me”** when asked who should be the designated
human reviewer in this project's Replit conversation is assigned the stable
project-local reviewer ID `reviewer-primary`. This person is separate from
the task agent. The project has no exported conversation decision identifier;
this is a procedural record of the user's designation, **not** an identity
attestation.

The designation only permits future review records to name this reviewer. It
does **not** approve a task, plan, tier, parameter set, policy, authorization
change, or local completion. The reviewer must personally inspect an exact
request and add an applicable committed decision under
`docs/validation/reviews/`; the coordinator then checks it. A task agent may
prepare a request but must not author the reviewer's decision. Until a real
decision, accepted runtime control, and verified final file-writer
coordination exist, ordinary activation and cutover remain blocked.
